# Hearthwatch feedback

Bug reports and feedback for [Hearthwatch](https://hearthwatch.group), a private
World of Warcraft group dashboard with a companion addon and Windows app.

[Open an issue](https://github.com/hearthwatch/hearthwatch-feedback/issues/new/choose)
if something is broken or wrong. Issues here are public: never paste your group
token, invite link or other private group details.

Hearthwatch is an unofficial fan project and is not affiliated with, endorsed
or sponsored by Blizzard Entertainment, Inc.
